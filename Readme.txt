# ⛏️ MC 字体转换工坊 (MC Font Forge)

一个专为《我的世界》(Minecraft) 资源包作者打造的轻量级、纯前端字体转换工具。无需安装任何软件，浏览器打开即用。

如果你曾尝试使用 **SnowB** 等位图字体生成工具制作 Minecraft 字体包，你一定会遇到各种莫名其妙的报错（比如游戏直接不加载、字体错位、甚至崩溃）。本工具正是为了解决这些痛点而生。

## ✨ 核心功能 (Features)

*   **🚀 纯前端运行**：单 HTML 文件，无需搭建服务器，不收集任何数据，绝对安全。
*   **🔄 FNT 转 JSON**：一键解析 SnowB 导出的 `.fnt` 文件，自动提取坐标并生成 MC 专用的 `default.json` 格式。
*   **🛡️ 全量 Unicode 转码**：彻底解决乱码问题。所有字符强制转换为标准的 `\uXXXX` 格式，并修复了 JSON 序列化导致的“多斜杠 (`\\u`)”错误。
*   **🧩 智能补齐 `\u0000`**：Minecraft 要求 `chars` 数组中的每一行长度必须完全一致，否则会报错或显示错位。本工具会自动找出最长的一行，并在末尾自动补齐 `\u0000` 占位符。
*   **📏 自定义高度与基线**：内置参数输入框，可自由设置 `height`（控制字体大小）和 `ascent`（控制字体上下位置），支持小数点微调。
*   **⚠️ 防崩溃保护**：自动检测 `ascent` 是否大于 `height`（这是 MC 字体包最常见的崩溃原因），如果越界会自动将其修正为安全值（高度的 80%）。

## 🛠️ 如何使用 (Usage)

1.  **准备文件**：使用 [SnowB](https://snowb.org/) 生成你的字体图集（推荐使用“有序网格打包”），并导出 `.fnt` 和 `.png` 文件。
2.  **打开工具**：下载本仓库的 `index.html`（或直接访问在线演示页），双击用浏览器打开。
3.  **上传文件**：在网页中上传你刚刚导出的 `.fnt` 文件。
4.  **填写路径**：输入你的 `.png` 图片在资源包中的相对路径（例如：`minecraft:font/my_font.png`）。
5.  **调整参数**：
    *   **Height**（默认 11）：控制字体大小，觉得字小就调大。
    *   **Ascent**（默认 10）：控制字体垂直位置，觉得靠下就调大。
6.  **生成并下载**：点击生成，预览无误后，点击下载 `default.json`。
7.  **放入游戏**：将生成的 `default.json` 和你的 `.png` 按照对应路径放入资源包，在游戏内按 `F3 + T` 重载即可。
